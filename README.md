# Nova University Student Portal

A static GitHub-ready front-end recreation inspired by the supplied university portal screenshot.

## Included
- Left university sidebar/navigation
- Profile page
- Personal / Parent / Guardian information cards
- Back and Update Student Data buttons
- Responsive mobile layout
- Collapsible sidebar
- Support chat bubble
- **No registration countdown/banner**

## Run locally

Just open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and `/root`.
6. Save.

## Customize the branding

Search `Nova University`, `NOVA`, and `student@nova.edu` in `index.html` and replace them with your demo university name/email.

This is a front-end demo only. It does not connect to a university database or process real student information.
